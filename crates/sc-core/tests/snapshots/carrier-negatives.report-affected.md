## Method and limitations

- Collected passively from public records (scan services, web archives, certificate logs). We did not open the submitted URLs, interact with the targets, or read or post to any callback channels.
- Records were linked by shared unique identifiers (inbox IDs, tags), by timing against the same target, and by probe chains (variants of one request to the same host and path, minutes apart). Linking is probabilistic.
- Model names inside requests are **not** reliable attribution: agents misreport who built them.
- Network attribution (ASN) identifies the hosting provider, not necessarily the developer of the agent.
- Public records cover a fraction of activity. Private or account-linked scans are invisible to us.
